# Oritech Addons One（Oritech：插件合一）

**🌐 语言：** [English](README.md) | [简体中文](README.zh-CN.md)

> 一个 Oritech 附属模组：把大量插件装进一个紧凑的扩展插件里、让它们无线工作，并新增五个 Oritech 本体没有的插件——其中两个能让机器通过自身各面输入输出物品。

## 📖 简介

**Oritech Addons One** 是 [Oritech](https://github.com/Rearth/Oritech) 的附属模组，出发点只有一个：**机器的插件槽太少**。它新增了

- **三种型号的扩展插件**：把 Oritech 自带插件装进去，并将其全部效果转发给它所连接的机器；
- **无线版本**的三个型号：不必贴着机器，隔着多远都能为那台机器提供插件效果；
- **五个自有插件**，补上 Oritech 本体没有的插件：仓储、储罐、区块加载与物品传输。

## 📦 新增内容

| 方块 | 作用 |
| --- | --- |
| **扩展插件Ⅰ / Ⅱ / Ⅲ型** | 装入 Oritech 插件，并把效果转发给它所连接的机器 |
| **无线扩展坞Ⅰ / Ⅱ / Ⅲ型** | 同样三个型号，但不需贴着机器，而是“连接”到机器 |
| **仓库插件** | 机器每个物品槽 +16 格容量 |
| **储罐插件** | 机器每个储罐 +8000 mB 容量 |
| **锚点插件** | 强制加载它所连接的那台机器所在的区块 |
| **扩展传输插件** | 让它所在方块（扩展插件/扩展坞）的六个面为机器输入输出物品 |
| **传输插件** | 同样的传输，但面是在机器的 3D 模型上点选 |

### 🧩 扩展插件

- **Ⅰ型**：装 Oritech 的**数值型插件**（速度、效率、终极、处理腔、电容、适配器）并累加它们的数值；本模组的仓库插件、储罐插件也能放进去。
- **Ⅱ型**：装**其余各类** Oritech 插件（含库存代理），插件的特殊效果与直接装在机器上完全一致。
- **Ⅲ型**：与Ⅰ型相同的数值型插件，但每种（类别, 等级）各占一个**专属槽位**，每格容量可配置（默认 256）。
- Ⅰ/Ⅲ型按**插件类别与等级**识别，而不是按方块本身，所以其它附属模组的分级插件（例如 [Oritech Things](https://github.com/Rearth/Oritech-Things)）同样适用。
- Ⅰ/Ⅱ型的槽位数可配置（默认 5 格，见下方“配置”一节）。
- 内部装有机器适配器插件时，扩展插件会成为该机器的能量输入点。

### 📡 无线扩展坞

- 用 Oritech 的**目标标识器**连接：先按住 Shift 右键无线扩展坞保存坐标，再按住 Shift 右键机器（机器上的插件、多方块核心都算）。
- 连接成功后，坞里的插件会隔着任意距离作用到那台机器；坞自己的界面会显示连接的机器、其坐标，以及该区块是否已强制加载。
- **机器的区块必须处于加载状态**，否则什么都不会生效。把**锚点插件**放进坞的保留槽里即可保持加载。
- 各种插件在坞里的表现与有线扩展插件完全一致，两个传输插件也一样。

### 🖥️ 界面

扩展插件与无线扩展坞共用同一个界面；每个标签页只在它所属的插件装在里面时才出现。

| 标签页 | 出现条件 | 作用 |
| --- | --- | --- |
| **插件** | 始终 | 方块的插件槽 |
| **无线** | 始终 | 连接的机器、坐标、区块状态，以及保留槽（放锚点插件） |
| **物品代理** | 内部装有 Oritech 的**库存代理**插件 | 让某个面代理机器库存中的一个槽位 |
| **扩展传输** | 内部装有扩展传输插件 | 本方块的六个面 |
| **传输** | 内部装有传输插件 | 以可旋转的 3D 模型显示所服务的机器 |

传输插件**放在世界里**时不是容器，只显示它自己的那一个页面。

### 🔁 传输

两个传输插件都在机器与它周围的容器之间搬运物品，每个面一个方向：

- 面可以是**输入**（往机器里送）、**输出**（从机器里取）、**输入输出**（两者都做）或未设置；
- 已配置的面可以打开**自动化**，让它每 tick 自己搬运；关掉时该面只是把库存提供给管道和漏斗；
- **严格遵守机器的槽位角色**——输入面只填机器的输入槽、输出面只清机器的输出槽，所以自动化既不会把产物槽塞满，也不会抽走机器的原料；
- 速率可配置（`transferItemsPerTick`，默认每个槽位、每个方向、每 tick 64 个）；
- **扩展传输插件**：放进扩展插件/无线扩展坞后，机器就能通过该方块的各个面进出物品；贴在 Oritech 的**机器扩展坞**上时，它配置的是那台扩展坞的六个面。它的页面是该方块的展开图。
- **传输插件**：可以放进扩展插件、直接放在机器上，或贴在机器扩展坞上。它的页面把所服务的机器画成可旋转的 **3D 模型**，结构上每个方块的每个面都能在模型上点选配置。

### 🎯 物品过滤

每个已配置的面都有一个**过滤**按钮，打开的过滤页面完全对齐 Oritech 自带的物品筛选器：

- **一个面两个过滤器**，输入与输出各一个——什么能进机器、什么能出机器是两个不同的问题；
- 每个过滤器 **12 个槽位**，可选**白名单或黑名单**；
- 可选匹配 **NBT** 与**数据组件**，因此两个原本相同的物品也能区分开；
- 空过滤器放行一切；从未配置过过滤器的面，行为与没有过滤功能时完全一样。

## ⚙️ 配置

`config/oritechaddonsone-common.toml`：

| 配置项 | 默认值 | 范围 | 含义 |
| --- | --- | --- | --- |
| `type1Slots` | 5 | 1 – 96（1.21.1）、1 – 72（26.1.2） | 扩展插件Ⅰ型可用的插件槽数 |
| `type2Slots` | 5 | 同上 | 扩展插件Ⅱ型可用的插件槽数 |
| `type3SlotCapacity` | 256 | ≥ 1 | 扩展插件Ⅲ型单个槽位能容纳的插件数量 |
| `transferItemsPerTick` | 64 | 1 – 6400 | 每个已配置面、每 tick、每个槽位、每个方向搬运的物品数 |
| `showWirelessDocksInAddonPage` | true | – | 在 Oritech 自带的插件页面里列出该机器的无线扩展坞（客户端显示选项） |

## 📋 配方

### 扩展插件

`A` = 钢锭，`B` = 机器扩展坞，`D` = 末影珍珠。三个型号共用同一个形状，只有中间的材料不同。

```text
有线      无线
ABA       ABA
ACA       ACA
          ADA
```

| 型号 | `C`（中间的材料） |
| --- | --- |
| Ⅰ型 | 处理器 |
| Ⅱ型 | 磁通门 |
| Ⅲ型 | 超级AI芯片，或用**堕落智能**代替 |

### 其余插件

| 产物 | 形状 | 材料 |
| --- | --- | --- |
| 锚点插件 | `ABA` / `ACA` / `DED` | A：塑料片 · B：铂锭 · C：末影之眼 · D：处理器 · E：强化护板 |
| 仓库插件 | `AAA` / `ABA` / `CDC` | A：塑料片 · B：箱子 · C：木板 · D：强化护板 |
| 储罐插件 | `AAA` / `ABA` / `CDC` | A：塑料片 · B：便携储罐 · C：硅 · D：强化护板 |
| 传输插件 | `" A "` / `BCB` / `BDB` | A：活塞 · B：塑料片 · C：处理器 · D：强化护板 |
| 扩展传输插件 | `" A "` / `BCB` / `BDB` | A：活塞 · B：塑料片 · C：处理器 · D：机器扩展坞 |

- **强化护板**指 Oritech 的任意一种强化护板（铜/铁/镍/碳，即 `oritech:plating` 标签）。
- **木板**使用原版的木板标签，任意木材都可以。
- 每条配方都会在配方书中自行解锁。

## 🚀 安装方法

1. 为你的 Minecraft 版本安装 [NeoForge](https://neoforged.net/)。
2. 下载对应版本的 **Oritech**，放入 `mods` 文件夹。
3. 下载 **Oritech Addons One**，放入 `mods` 文件夹。
4. 启动游戏即可享用！

## 🧷 备注

- 扩展插件无法被 Oritech 的插件绞接器使用。
- 无线扩展坞只有在机器的区块处于加载状态时才生效——这正是锚点插件的用途。
- 两种精炼厂都会得到本模组为 Oritech 界面补上的插件数值面板，机器的无线扩展坞也可以列在 Oritech 自带的插件页面里。
