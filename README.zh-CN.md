# Oritech Addons One（Oritech：插件合一）

**🌐 语言：** [English](README.md) | [简体中文](README.zh-CN.md)

> 一个提供了三种型号扩展插件的 Oritech 附属，帮助你节省插件占据的空间。

## 📖 简介

**Oritech Addons One** 是 [Oritech](https://github.com/Rearth/Oritech) 的一个附属模组，新增了**三种型号的扩展插件**。相比放置多个独立的插件，使用这些紧凑版本可以显著减少它们所占用的空间。

## ✨ 特性

- 三种型号的扩展插件
- 相比原版 Oritech 插件更节省空间
- 与 Oritech 机器无缝集成

## 📦 前置模组

### 必需

- [Oritech](https://github.com/Rearth/Oritech)

### 可选 / 联动

- [Oritech Things](https://github.com/Rearth/Oritech-Things)

## 🚀 安装方法

1. 为你的 Minecraft 版本安装 [NeoForge](https://neoforged.net/)。
2. 下载对应版本的 **Oritech**，放入 `mods` 文件夹。
3. 下载 **Oritech Addons One**，放入 `mods` 文件夹。
4. 启动游戏即可享用！
